# Язык программирования DoMtor 🚀

**DoMtor** — это легкий язык программирования, похожий на Python, созданный для новичков. 
В нём все ключевые слова и встроенные библиотеки переведены на русский язык, что делает его идеальным инструментом для обучения без языкового барьера.

Написан на чистом Python. Переводит код в Python на лету.

## ✨ Особенности
* **Русский синтаксис:** Ключевые слова, такие как `если`, `для`, `печать`.
* **Готовый GUI (Графика):** Создание приложений с помощью библиотеки `окна`.
* **Создание игр:** Разработка игр с помощью библиотеки `игра`.
* **Сайты и Боты:** Встроенные библиотеки для сайтов на Flask, а также для ботов в Telegram, Discord и VK.
* **Полная кастомизация:** Любую команду или библиотеку можно переименовать прямо в админ-панели.
* **Экспорт в EXE:** Компиляция программ в отдельные исполняемые файлы для Windows.

## 📦 Установка
1. Склонируйте репозиторий (или скачайте ZIP-архив):
   `git clone https://github.com/ТВОЙ_НИК/domtor.git`
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Запустите Админ-панель (IDE):
   `python admin.py`
